# Privacy Policy

**Pyrolysis Furnace Intelligence**  
Publisher: **Abbas Rajaei**  
Effective date: **14 September 2026**

## Overview

Pyrolysis Furnace Intelligence is a desktop engineering application for educational, technical, and portfolio use. It provides interactive calculations and visualisations related to furnace combustion, heat transfer, thermal efficiency, and pyrolysis process behaviour.

The application is designed to run locally on the user's Windows device.

## Personal information

Pyrolysis Furnace Intelligence does not intentionally collect, store, transmit, sell, rent, or share personal information with the publisher or with third parties.

The application does not require a user account, login, profile, or registration.

## Engineering data entered by the user

Engineering values entered into the application, such as fuel composition, furnace operating conditions, temperatures, feed rates, steam ratios, or other process inputs, are processed locally on the user's device for the purpose of performing calculations and displaying results.

These inputs are not intentionally transmitted to the publisher or to an external cloud service by the application.

Users should nevertheless avoid entering confidential, proprietary, export-controlled, or safety-critical plant information unless they are authorised to do so.

## Local application service

The desktop application uses a local Dash/Flask web service to provide its graphical user interface.

This service runs on the user's own computer and communicates through the local loopback interface. It is used only to operate the desktop application interface and perform the application's engineering calculations.

The application does not use this local service as a cloud data-transfer mechanism.

## Analytics, telemetry, advertising, and tracking

The application does not intentionally include:

- advertising;
- behavioural tracking;
- third-party analytics;
- publisher-operated telemetry;
- location tracking;
- marketing trackers;
- profiling of users.

## Device capabilities

The application does not intentionally request or use access to:

- camera;
- microphone;
- precise location;
- contacts;
- photos;
- personal documents;
- Bluetooth;
- NFC;
- telephony;
- Xbox services.

The Microsoft Store package is a packaged desktop application and declares the `runFullTrust` capability so that the existing desktop executable can run. This capability is not used by the application to intentionally collect personal information or to perform administrative changes to the user's system.

## Network activity

The application is designed primarily for local operation.

Its user interface is served locally from the user's own device. The application does not intentionally transmit engineering inputs or calculation results to the publisher.

Operating-system components, installation services, Microsoft Store services, browser components, or other software on the user's device may independently generate network traffic under their own privacy policies. Such activity is outside the application's direct control.

## Data retention

Because the application does not intentionally collect personal information on behalf of the publisher, the publisher does not maintain a server-side retention database for user data.

The application does not intentionally provide cloud synchronisation or cloud backup of engineering inputs.

## Data sharing

The publisher does not intentionally sell, rent, or share user personal information or engineering inputs with third parties through the application.

## Children

Pyrolysis Furnace Intelligence is an engineering and educational tool and is not specifically directed at children.

## Security and limitations

The application is intended as an educational and engineering workbench. It is not a plant digital twin, safety system, burner management system, advanced process controller, or substitute for plant procedures, engineering verification, or professional judgement.

Users are responsible for protecting any information they choose to enter into the application and for following their organisation's data-handling and cybersecurity requirements.

## Changes to this policy

This privacy policy may be updated if the application's functionality changes, particularly if future versions add features such as cloud services, telemetry, accounts, remote storage, or external integrations.

Material changes will be reflected in this document and in the application's public repository.
