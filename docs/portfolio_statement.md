# Portfolio statement

Developed **Pyrolysis Furnace Intelligence 2.0**, an interactive furnace engineering workbench that combines ideal combustion calculations, mixture LHV/Wobbe analysis, static heat accounting, conserved six-zone firing distribution, process/control scenarios, sensitivity analysis and context-sensitive engineering guidance. The interface supports automatic fuel-composition normalization, baseline/current comparison, saved cases, bounded draft teaching correlations and explicit separation of calculated, assumed, qualitative and unavailable engineering conclusions. The public model uses synthetic teaching data and makes no plant-validation, safety-system or autonomous-control claim.
